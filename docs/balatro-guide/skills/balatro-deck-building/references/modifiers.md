# Card modifiers

A playing card has at most one enhancement, one edition and one seal. Replacing one layer removes its previous modifier while preserving the other layers unless the effect says otherwise.

| Enhancement | Baseline effect |
| --- | --- |
| Bonus | +30 Chips when scored |
| Mult | +4 Mult when scored |
| Wild | Every suit, no rank substitution; suit Bosses can debuff it |
| Glass | ×2 Mult when scored; 1-in-4 destruction chance after scoring |
| Steel | ×1.5 Mult while held during scoring |
| Stone | 50 Chips; no active rank/suit; additional scoring card when played |
| Gold | $3 when held at round end |
| Lucky | Separate 1-in-5 chance for +20 Mult and 1-in-15 for $20 when scored |

| Edition | Effect |
| --- | --- |
| Foil | +50 Chips |
| Holographic | +10 Mult |
| Polychrome | ×1.5 Mult |
| Negative | Additional capacity for its owned Joker/consumable type; not an ordinary base-game playing-card edition |

| Seal | Trigger |
| --- | --- |
| Gold | $3 when scored |
| Red | One extra eligible card activation, including supported held effects |
| Blue | When held at round end, creates Planet for the final played hand if capacity permits |
| Purple | When discarded, creates random Tarot if capacity permits |

Debuffs suppress ordinary card effects and can preserve classification. A debuffed Wild loses all-suit behavior; the exact rank/suit behavior of debuffed Stone and uncommon modifier hooks requires matching-build verification. Negative capacity is an exception to ordinary debuff suppression. Sticker mechanics belong in [decks/stakes](../../balatro-decks-stakes/references/decks-stakes.md).

Red repeats eligible effects, not a new whole hand. Glass destruction occurs after scoring; do not count a new independent destruction roll for each retrigger without matching evidence. Oops! All 6s modifies listed probabilities; use the actual effect rather than treating every random process as doubled.
