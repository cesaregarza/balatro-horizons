# Evaluate the whole Joker engine

Read [mechanics](references/mechanics.md) for trigger phases and copying. Use current public effect text and counters for each Joker; the examples cover common interactions rather than every Joker.

Evaluate an effect by what it adds to realistic hands and future opportunities: Chips, additive Mult, multiplication, retriggers, income, consistency, rule changes or utility. Rarity and printed ceiling are insufficient. A support Joker's value includes the other effects it enables.

A scaler needs time and affordable activation. Compare its next-Blind output with the bridge it displaces, then its likely value before the revealed Boss. A static Joker need not be sold at an arbitrary Ante or contribution percentage; an Eternal commitment need not be worthless merely because it provides income.

Order by actual trigger phase, copy direction and dependencies. Simple independent additions often precede multipliers, but no global sort handles all copies, first-card effects and sacrifices. Copy-target changes between legal settled actions can serve different phases; do not assume an animation-time reorder exists.

Before buying or selling, evaluate stickers, Negative capacity, cash-linked scoring and Boss resilience. Preserve a dependency only while the actual alternatives justify it. One disabled Joker may matter more than several small score differences; redundancy costs a slot and is conditional on the revealed problem.

Choose an actual replacement or order, with an optional short note about the dependency changed. Re-observe afterward.
