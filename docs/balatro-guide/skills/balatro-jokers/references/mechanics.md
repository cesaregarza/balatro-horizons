# Joker mechanics and trigger vocabulary

Use the current Joker text and dynamic counters to identify its trigger, value and compatible copy targets.

| Wording / role | Relevant event |
| --- | --- |
| Blind selected / start of round | Selection/start resource change |
| Before scoring / when hand played | Pre-scoring hook; exact wording and implementation matter |
| Each scored card / when scored | Per-card scoring hook |
| Held in hand | Held-card scoring or round-end hook as specified |
| Independent +Chips, +Mult, ×Mult; contains/is a hand | Joker's independent scoring contribution unless effect says otherwise |
| Gains / loses / resets | Value changes at the named event, contributes at its own scoring phase |
| Retrigger | Eligible additional scored/held card activation |
| Discarded / sold / destroyed / reroll / pack skip / round end | Named event; do not substitute another event because cards leave the same area |

Blueprint copies the immediately right-hand Joker's compatible ability. Brainstorm copies the leftmost Joker's compatible ability; **it does not search rightward for the first compatible Joker**. A missing or incompatible target does not authorize another target. Editions/stickers are not copied as abilities, and copying current scaler output does not generally duplicate its permanent growth. Multi-copy/cycle behavior requires matching evidence.

During the independent pass, Foil/Holographic precedes the Joker's own ability and Polychrome follows it. Per-card Jokers act during card events regardless of row position relative to independent +Mult. Other-Joker hooks can complicate a simple sort.

In this rules baseline, Hanging Chad retriggers the first scoring card twice. Photograph gives ×2 on the first scoring face card and its eligible retriggers. If that first scorer is a valid face and both effects apply, three activations contribute ×8 to Mult available at those events. Later independent +Mult is not multiplied retroactively. Face debuffs and actual first-scorer identity matter.

Vampire may remove an enhancement before its scoring contribution; use the resulting state rather than awarding the removed Glass/Bonus/etc. effect as well.
