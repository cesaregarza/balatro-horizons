# Read the actual modifiers

Read the [deck/stake reference](references/decks-stakes.md) for starting modifiers and cumulative difficulty changes.

Record observed cards, resources, cash, capacity, vouchers/consumables and final scoring rule. Accumulate stake effects; then account for actual Boss, Joker and challenge changes. A deck name is not proof of the current hand count.

Green removes the ordinary interest incentive, not cash's other value. Painted raises hand-size flexibility but slot competition. Black's extra Joker slot has an immediate hand-resource cost. Abandoned and Checkered change the available opening patterns; neither proves a hand is automatic. Anaglyph creates tag opportunities, not a required skip schedule.

Plasma rewards the effective sum entering its balancing formula; a lower-component purchase is not automatically better. Compare actual gain, including multiplication and rounding, rather than trying to equalize components before balancing.

At higher stakes, include all earlier restrictions. Judge Eternal commitment, Perishable expiry and Rental payments against the actual expected holding horizon. Do not import older Orange pack-price or Gold hand-size penalties into this 1.0.1 rules baseline. Unknown challenge/mod changes require matching effect data.
