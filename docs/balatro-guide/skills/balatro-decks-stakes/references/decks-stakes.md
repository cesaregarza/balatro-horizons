# Deck and stake baseline

Starting modifiers combine with cumulative stakes and active Joker, voucher, Boss or challenge effects. Use the resulting public values.

| Deck | Starting modifier |
| --- | --- |
| Red | +1 discard per round |
| Blue | +1 hand per round |
| Yellow | +$10 starting cash, ordinarily $14 total |
| Green | No interest; $2 per unused hand and $1 per unused discard |
| Black | +1 Joker slot; −1 hand per round |
| Magic | Crystal Ball and two Fools |
| Nebula | Telescope; −1 consumable slot |
| Ghost | Hex; Spectrals may appear as shop offers |
| Abandoned | 40 cards, no J/Q/K |
| Checkered | 26 Spades and 26 Hearts |
| Zodiac | Tarot Merchant, Planet Merchant, Overstock |
| Painted | +2 hand size; −1 Joker slot |
| Anaglyph | Double Tag after each Boss defeated |
| Plasma | Balance Chips/Mult before scoring; doubled base Blind sizes; exact rounding unresolved |
| Erratic | Randomized starting ranks/suits; inspect actual public multiset |

| Stake | Added constraint; earlier stakes also apply |
| --- | --- |
| White | Baseline |
| Red | Small Blind base reward removed |
| Green | Faster target scaling |
| Black | Eternal shop Jokers possible |
| Blue | −1 discard per round |
| Purple | Further target scaling |
| Orange | Perishable shop Jokers possible |
| Gold | Rental shop Jokers possible |

Orange and Gold use Perishable and Rental rules in this baseline. Read sticker eligibility and actual unlock/challenge restrictions from the current game.

Challenges add a separate layer: actual deck composition, starting items, banned content, capacities, money/scoring rules and resource limits. Profile unlock availability is not enumerated. An unlock objective differs from a run-win objective; neither pack is a complete challenge/mod catalog.

Eternal prevents ordinary sale/destruction. Perishable normally debuffs after five productive rounds; read actual remaining counters and debuffs. Rental normally has $1 acquisition price and charges $3 per round, potentially producing debt. Stickers can combine where allowed; do not assume every combination is legal. A debuffed Perishable can remain sellable and retain Negative capacity. Negative capacity disappears when that owned object is removed. Precise timer pauses, stacking eligibility and settlement order remain unresolved.
